Adds Hermes Guardian, a standalone native plugin with one pre_tool_call hook and no tools, middleware or third-party runtime dependencies. Version 0.2.0 also registers an operator CLI for proposal, simulation, review and confirmed activation. The submitted YAML must pin the owner-approved public release commit before opening this PR.

Guardian evaluates deterministic rules, protected local POSIX paths and a deliberately small shell grammar. It delegates approval to Hermes and keeps metadata-only decision audits. Existing security plugins overlap substantially; the distinction is its narrow local scope, payload minimization and lack of an SDK, external service or model reviewer, not a new security category. Policy Lab adds hypothetical regression simulation using the exact enforcement evaluator, increasing overlap with Policy Backtester; it does not claim novel policy simulation.

Runtime disclosure: reads settings and filesystem metadata/symlink targets, writes owner-only redacted JSONL in sanctioned plugin storage, and the enforcement hook does not read credential-file contents, make network/model calls, spawn subprocesses or modify core. Optional `--model` generation sends user instructions and configured policy paths through public ctx.llm to the active provider (charges may apply); no live inference was tested in the credential-free validation environment. Confirmed operator activation uses public ctx.set_config and stores private policy backups. The offline builder is an exact language template, not a general model. Development harnesses invoke the real host and are not plugin dependencies.
